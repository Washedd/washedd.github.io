I'm **Ethan Byrne**, a software developer based in the UK. Most of my work sits at the intersection of online games, community platforms, and small web services.

I build Discord bots and game-server tooling: FiveM roleplay stacks, Rust+ companion integrations, and the glue that keeps those communities running. Alongside that I write web interfaces and utilities — trading scanners, auth and login systems, and Python tools — in JavaScript, TypeScript, Lua, and Python.

Public work includes a rustplusplus fork for the Rust+ companion app and FiveM tutorial code from Jeva. A larger body of Discord, roleplay-server, and web projects stays private; the Projects list names them without exposing source.
