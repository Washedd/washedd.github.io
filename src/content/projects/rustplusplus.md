A Discord bot built on `rustplus.js` so a Rust game server can surface smart devices, events, and companion-app data in a channel.

This is a working fork of the rustplusplus project — used and extended around quality-of-life features rather than a from-scratch rewrite.

`open rustplusplus.md` jumps to the GitHub repo.
